# Regole del progetto

Questo repository è pubblico e diventerà un piccolo sito pubblicato con GitHub Pages.

- **Sito statico**: solo HTML, CSS e JavaScript. Nessuna libreria esterna, nessun passaggio di build.
- **`index.html`** nella cartella principale, e solo percorsi relativi (deve funzionare su GitHub Pages).
- I contenuti stanno in file di testo semplici, separati dal codice, così l'insegnante può modificarli senza saper programmare.
- Commit piccoli e frequenti, con messaggi in italiano che spiegano cosa è cambiato.
- Usa sempre `git` da riga di comando, mai `gh` (non è installata). Prima di ogni `git push` chiedi conferma.
- Spiega ogni azione con parole semplici: l'utente non è un programmatore.
- Repository pubblico: niente dati personali reali di studenti (nomi, foto, voti, ecc.).
